# StripCash Attribution — StripUnion

## Objective

Connect each StripUnion affiliate click to a stable StripCash-side identifier so revenue optimization can move beyond raw click counts.

## Confirmed parameters

From the StripCash Links & Creatives UI and documentation supplied by the account owner:

- `sourceId` is supported on regular links
- `p1`, `p2`, `p3` are supported custom parameters
- Link Builder also exposes Click ID for postbacks, Campaign, Creative and Source
- StripCash reports commercial outcomes including clicks, signups, verified signups, first purchases, total purchases and scheme earnings

## Phase 1 implementation

Every Stripchat affiliate link generated by StripUnion now adds:

- `sourceId=stripunion`
- `p1=<page_or_placement_source>`

Examples:

- `homepage_hero`
- `stripchat_top`
- `stripchat_mid`
- `stripchat_bottom`
- `stripchat_pricing_hero`
- `stripchat_vs_chaturbate_mid`
- `chaturbate_alternatives_bottom`

The same source value is also emitted to the client-side `affiliate_click` dataLayer event.

## Why p1 carries placement

A stable page/placement identifier lets StripUnion compare downstream conversion quality instead of optimizing only for CTR.

Desired analysis:

```
affiliate_source
→ clicks
→ signups
→ verified signups
→ first purchases
→ purchase value
→ scheme earnings
```

## Phase 2 — pending exact Link Builder mapping

Before using Campaign, Creative, Source and postbacks in code, capture the exact final URL generated by StripCash after entering sample values in Link Builder.

Recommended sample:

- Click ID for postbacks: leave blank
- Campaign: `su_test`
- Creative: choose a text-link-safe/default value if required
- Source: `stripunion`

Then record the generated Final URL so parameter names and value behavior are confirmed rather than guessed.

## Phase 3 — postback / server-side revenue events

Do not build a postback receiver until traffic volume justifies it.

Initial optimization can use StripCash Statistics plus StripUnion click analytics. Add server-side postbacks when:

- traffic is material
- campaign-level conversion decisions are frequent
- first-purchase attribution needs automated joining to page/session data

## Primary commercial KPI

The current account uses 20% RevShare.

Therefore optimize for:

1. first purchases
2. purchase value / repeat spending
3. scheme earnings
4. signup-to-first-purchase rate

CTR is diagnostic, not the business objective.
