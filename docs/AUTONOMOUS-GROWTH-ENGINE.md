# StripUnion Autonomous Growth Engine

## Objective
StripUnion is an affiliate-acquisition business. The growth engine should increase qualified traffic first, then optimize the funnel from visit -> affiliate click -> signup -> verified signup -> first purchase -> repeat purchase -> affiliate revenue as those data sources become available.

## Continuous learning dimensions
The system should not overfit to whatever topic was most recently discussed. Each daily/weekly cycle should inspect the whole operating surface:

- Demand and search intelligence: GSC/Bing queries, SERP coverage, indexation, keyword/topic gaps.
- Content architecture: reviews, comparisons, pricing/tokens, guides, creator-referral content, taxonomy, cannibalization, freshness, internal-link structure.
- Visual/editorial quality: hero imagery, platform cards, tables, screenshots/approved creatives, scannability, mobile presentation, share-card quality.
- Distribution: X/Buffer, community/referral traffic, IndexNow, syndication, partner/referral channels, future adult-friendly paid traffic.
- UX and conversion: CTA placement, page hierarchy, comparison UX, outbound click-through, landing-page fit, mobile behavior.
- Monetization: affiliate-offer coverage, click/signup/first-buy/repeat-purchase/revenue attribution, EPC and revenue/session once connected.
- Technical growth: crawl/index health, canonical/sitemap/robots, performance, deployment health, analytics integrity.
- Trust and compliance: consent, privacy, accurate claims, age-appropriate adult positioning, official-source verification.
- Supply-side growth: creator/model referral content and partner onboarding only; no studio/agency operations.

## Cadence
Daily: collect first-party and competitor evidence; update opportunity scores; select quality-gated new content; publish 1-3 strong items when safe; verify indexability, internal links, featured image, social distribution, and approved affiliate CTA behavior.

Weekly: review the complete funnel and competitor architecture, identify structural gaps, and prioritize the next clusters/experiments.

7/14/30-day windows: judge meaningful changes to established pages, CTA layouts, SEO targeting and distribution tactics. Avoid reacting to one-day ranking noise.

## Daily publishing rule
Daily publishing is encouraged because StripUnion currently has a large content gap, but publishing volume is subordinate to quality. Every published item should add original decision-support value and should not be a near-duplicate of an existing page. Where a WordPress draft exists, prefer upgrading the draft over generating another overlapping article.

Before publication, require at minimum:
- clear search/user intent;
- factual claims that can be supported from stable or official evidence;
- non-duplicate/cannibalization check;
- useful H2/H3 structure and structured comparison where relevant;
- SEO title/meta/focus keyword;
- meaningful internal links between Blog and Main where appropriate;
- a tasteful non-explicit featured image or approved creative;
- no outbound affiliate CTA for unapproved programs;
- no unsupported price, traffic, earnings, testimonial, or ranking claim.

## Competitor intelligence V2 direction
Move beyond URL counting. Learn each benchmark's site architecture, content clusters, page-type mix, visual density, CTA patterns, platform/offer coverage, freshness cadence, pricing/comparison structures, internal linking, and expansion into adjacent categories. Convert these observations into evidence-backed opportunities rather than copied content.

## Learning memory
For each material experiment, preserve: hypothesis, target page/audience, change, evidence window, traffic/click/conversion/revenue outcome when available, confidence, and decision (winner/loser/inconclusive). Future opportunity ranking should incorporate these learned rules.

## Human approval boundaries
Keep DNS, billing, production credentials, legal-policy decisions, new affiliate contracts, payout destinations, large paid-media budgets, and any creator/studio contractual arrangement outside autonomous execution unless explicitly approved.
